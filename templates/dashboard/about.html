About the Project

Air Quality Prediction and Anomaly Detection System

Overview

This project predicts the Air Quality Index (AQI) and detects unusual pollution levels using Machine Learning. Air quality data is collected in real time from the OpenWeatherMap Air Pollution API for Kathmandu (27.72°N, 85.32°E), stored in a SQLite database, and used to train prediction and anomaly-detection models.

Key Features

Live AQI Monitoring

Latest pollutant concentrations and AQI from the local database with health recommendations.

AQI Prediction

Random Forest model predicts the AQI from pollutant levels and time features.

Historical Trends

Line charts of AQI and PM2.5 over time from the stored records.

Anomaly Detection

Isolation Forest flags unusual air-quality readings.

Technologies

  • Data collection: Python, OpenWeatherMap API, APScheduler
  • Database: SQLite
  • Preprocessing & EDA: Pandas, NumPy, Matplotlib
  • Machine Learning: scikit-learn (Random Forest, Isolation Forest)
  • Web application: Django

OpenWeatherMap AQI Scale

  • 1 — Good — Air quality is good
  • 2 — Fair — Air quality is acceptable
  • 3 — Moderate — Some pollution is present
  • 4 — Poor — Air quality is unhealthy
  • 5 — Very Poor — Air quality is very unhealthy
