About the Project

Air Quality Prediction and Anomaly Detection System

Overview

This project predicts the Air Quality Index (AQI) and detects unusual pollution levels using Machine Learning. Air quality data is collected in real time from the OpenWeatherMap Air Pollution API for Kathmandu (27.72°N, 85.32°E), stored in a SQLite database, and used to train prediction and anomaly-detection models.

The AQI is calculated using the U.S. EPA breakpoint interpolation method, producing values on the standard 0–500 scale. The API provides raw pollutant concentrations in μg/m³, which are converted to the appropriate EPA units (ppm for CO, ppb for NO₂, O₃, SO₂) before applying the breakpoint tables.

Key Features

Live AQI Monitoring

Latest pollutant concentrations and EPA AQI from the local database with health recommendations.

AQI Prediction

Random Forest model predicts the EPA AQI (0–500) from pollutant levels and time features.

Historical Trends

Line charts of AQI and PM2.5 over time from the stored records.

Anomaly Detection

Isolation Forest flags unusual air-quality readings.

Technologies

  • Web application: Django

U.S. EPA AQI Scale (0–500)

  • 0-50: Good - Air quality is satisfactory, little or no risk
  • 51-100: Moderate - Acceptable; sensitive individuals may be affected
  • 101-150: Unhealthy for Sensitive Groups - Sensitive groups may experience health effects
  • 151-200: Unhealthy - Everyone may begin to experience health effects
  • 201-300: Very Unhealthy - Health alert: everyone may experience serious effects
  • 301-500: Hazardous - Health emergency for the entire population

AQI Calculation Methodology

The AQI is calculated using the U.S. EPA breakpoint interpolation formula:

AQI = ((AQIhigh - AQIlow) / (BPhigh - BPlow)) × (C - BPlow) + AQIlow

Where C is the pollutant concentration. The overall AQI is the maximum of the individual sub-indices for PM2.5, PM10, CO, NO₂, O₃, and SO₂.

Pollutant concentrations from the OpenWeatherMap API (μg/m³) are converted to EPA standard units: CO → ppm (MW=28.01), NO₂ → ppb (MW=46.01), O₃ → ppb (MW=48.00), SO₂ → ppb (MW=64.06), at 25°C and 1 atm.
